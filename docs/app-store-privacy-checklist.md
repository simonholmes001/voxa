# App Store Privacy Checklist

Status: draft checklist for TestFlight expansion and App Store submission.
Related issue: #85.
Source baseline: `docs/privacy-security-assurance.md`.

## App Store Connect App Privacy Answers

Use the privacy inventory before completing App Store Connect. The current MVP
appears to collect the following data categories:

| Apple Category | Voxa Examples | Linked to User | Tracking | Purpose |
| --- | --- | --- | --- | --- |
| User ID | Backend-issued user ID derived from Apple subject | Yes | No | App functionality, product personalization |
| Other User Content | Typed practice questions, translation text, goals, generated lesson/debrief content | Yes | No | App functionality, product personalization |
| Audio Data | Voice tutor audio and speech-recognition input | Yes | No | App functionality, product personalization |
| Photos or Videos | Photo/camera image translation payloads | Yes | No | App functionality |
| Product Interaction | Session duration, lesson/progress/review activity | Yes | No | App functionality, product personalization |
| Other Diagnostic Data | Correlation IDs, endpoint status, operational diagnostics | Yes | No | App functionality, analytics |

Do not answer "data not collected" while the current backend and AI features are
enabled.

## Privacy Policy Must Cover

- What Voxa collects during sign-in, onboarding, tutoring, translation,
  image translation, debrief, course generation, and diagnostics.
- Why the data is collected and how it is used to personalize learning.
- Which providers process data: Apple, Microsoft Azure, OpenAI, GitHub Actions
  for CI/CD, and any TestFlight/App Store services.
- Whether data is linked to identity.
- Whether tracking is performed. Current engineering position: no tracking.
- Retention periods for learner state, generated courses, debrief evidence,
  refresh sessions, audit/rate-limit rows, and logs.
- Account deletion, data export, and correction request channels.
- International transfer/subprocessor language for non-UK/EU processing where
  applicable.

## In-App Requirements

- Configure `VOXA_PRIVACY_POLICY_URL` and verify the Privacy policy row in
  Settings/More opens the published policy.
- Verify the Settings/More Delete account flow deletes account data and signs
  the user out.
- Verify the Settings/More Export my data flow returns a portable JSON export.
- Keep permission prompts contextual:
  - Microphone: spoken tutor and voice input.
  - Speech recognition: ask/translate by voice.
  - Camera/photos: image translation.
  - Notifications: only if reminders are implemented.
- Avoid requesting permission during first launch unless the user starts the
  relevant feature.

## Required Reason API Audit

The app currently uses `UserDefaults` for app-specific onboarding draft and
tutor preference state. The privacy manifest declares:

- `NSPrivacyAccessedAPICategoryUserDefaults`
- Reason `CA92.1`

Re-run this audit whenever adding an SDK or Apple API that may use:

- file timestamps,
- system boot time,
- disk space,
- active keyboards,
- UserDefaults.

## Reviewer Notes Before Submission

Prepare App Review notes that explain:

- Sign in with Apple is required for cross-device learning state.
- Microphone/speech permissions are only used for language learning voice
  features.
- Camera/photo access is only used for image translation initiated by the user.
- AI responses are generated by OpenAI-backed services; permanent OpenAI keys
  are not included in the app.
- Where the user can find privacy policy, data export, and account deletion
  controls.

## Blockers

Do not submit to App Review until these are resolved:

- No published privacy policy URL.
- App Store Connect privacy answers not reconciled with the privacy manifest.
- Privacy manifest not reconciled with Xcode's generated privacy report.
- Account deletion/export not verified against the deployed production storage
  account.
